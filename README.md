\# 🏦 Fintech Credit Card Lead Intelligence AI



An enterprise-grade financial technology solution powered by a \*\*Robust Voting Ensemble Architecture Engine\*\*. This system utilizes advanced demographic profiling and real-time financial data analytics to identify high-potential credit card conversion targets.



Developed to empower financial relationship desks with highly reliable, bias-free, and scalable customer acquisition insights.



\---



\## 🚀 Key Production Features



\- \*\*Robust Voting Ensemble:\*\* Synthesizes predictions using `XGBoost`, `LightGBM`, and `RandomForest` via a soft-voting classifier for ultimate stability.

\- \*\*Anti-Bias Data Engineering:\*\* Completely filters out uninformative synthetic representations and utilizes `SMOTE` balancing combined with exact `StandardScaler` mathematical pipelines.

\- \*\*Enterprise Smart UI:\*\* Powered by Streamlit, offering desktop and fully responsive mobile layouts with descriptive lead sourcing mapping.

\- \*\*Dual Workflow Design:\*\* Supports both real-time \*\*Single Customer Profiling\*\* for instant sales calls and \*\*Batch File Processing\*\* for bulk campaign spreadsheet extraction.



\---



\## 📊 Core Data Engine \& Feature Profile



Based on advanced feature importance analytics, the model weighs customer attributes realistically, eliminating legacy systemic bias:



1\. \*\*Age Spectrum \& Longevity (Vintage):\*\* Primary anchors for financial baseline maturity.

2\. \*\*Employment \& Sourcing Structure:\*\* Distinguishes acquisition efficiency across channels (Branch visits, Digital App/Web apps, Telemarketing, and DSAs).

3\. \*\*Liquidity Context (Avg Monthly Balance):\*\* Transformed via stable production scaling layers to protect boundary predictions.
